## Resulting behavior

state. Explicit install is additive; a successful tool becomes a member only
after its complete payload/data/aliases are healthy. Complete uninstall removes
all proven selected release/selector scope before retiring membership. Update
adopts/reconciles before refresh, freezes the actual managed set, and continues
under freshly fetched code with the same PID/tickets/pair/generation. Completed
uninstall cannot be resurrected by an unrelated install then update. Retired or
unsupported managed members remain protected and visible. No expected-tools file
or remembered profile selects future work.

Identity/data parsing, exact owned-selector repair B, live recursive deletion C
and health are distinct. A saved receipt cannot authorize recursive deletion when
payload proof is missing. Staging/checksum/extraction/library qualification finish
before guarded publication. Durable per-path intentions precede mutations; the
common prior-journal gate applies before every new lifecycle batch. Recognized
partial removal can retain member/protected evidence while permitting repair;
foreign/unresolved scope blocks journal replacement. Bakery tickets and registered
blocked-child/arm/exec leases keep all required roots busy after owner SIGKILL
while a publication utility is still alive. Native Git auto-maintenance is disabled
per fetch/reset command so detached work cannot outlive its registered lease.

than healthy-only inventory. Their fully buffered output is generation/child-ticket
fenced and read-only. Check merges required environment/rc/PATH diagnostics while
optional helpers/fzf hints remain informational. It never executes payloads,
loads libraries, sources rc/hooks or writes index/cache/state. Login welcome uses
a cheap lazy managed summary and preserves existing issue replay/deduplication.
Prune apply uses PREFIX-only locking, complete all-slot/pending/protected claims
and immediate live C revalidation before every registered deletion; dry-run is
strictly read-only and unrelated journals are not recovered.
