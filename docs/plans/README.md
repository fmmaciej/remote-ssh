# Implementation Plans

Store approved implementation plans and their task records here. Name each
plan after its task, for example `tool-checksums.md`; the filename does not need
`plan` or `implementation-plan`.

For tasks using the [multi-agent workflow](../multi-agent-workflow.md), present
the initial plan to the human before saving it here. After approval, preserve
the agreed plan and record repair rounds, audit outcomes, and validation results
without rewriting the approval history.

## Plans

- [Tool checksums](tool-checksums.md): pinned SHA-256 coverage, explicit upstream
  exceptions, and offline verification.
- [Binary selection](binary-selection.md): deterministic executable discovery,
  explicit paths, and installation failure behavior.
